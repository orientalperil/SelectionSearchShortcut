Selection Search Shortcut

Shortcuts

Alt + 1 Search the selected text in a new tab next to this one, and switch to it.
Alt + Shift + 1 Same, but stay on the current tab.

Search results always come from your browser's default search engine, and the new tab always opens directly to the right of the tab you're on - not at the end of the tab strip.

Changing the shortcuts

Keyboard shortcuts are managed by the browser itself, not by this extension.

Chrome

Open chrome://extensions/shortcuts and find "Selection Search Shortcut".

Firefox

Find "Selection Search Shortcut" in the shortcut list that opens.

If the button doesn't work: open about:addons, click the gear icon in the top-right corner, then choose Manage Extension Shortcuts.

Known conflicts

  • On some Linux window managers and on ChromeOS, Alt+1 switches to the first pinned tab. If that happens, rebind the shortcut above.
  • On macOS, Alt is the Option key and can produce accented characters in some layouts. Rebind if it interferes with typing.
